📖 籌碼資料來源與指標判讀指南
1. 資料來源與自動抓取方式
本看板每日數據均來自台灣期貨交易所 (TAIFEX) 與 台灣證券交易所 (TWSE) 官方公開資料。系統於每日下午 18:05 自動啟動 Python 爬蟲更新數據並刷新圖表。
2. 各項指標意義與計算方式
  • 外資台指期淨未平倉：外資期貨多空未平倉單差額，負值代表空單較多（避險需求高）。
  • 散戶多空比 (小台/微台)：-(三大法人淨未平倉量 / 全市場未平倉總量) * 100%。散戶常為反指標，數值 ≥ 20% 代表過熱偏多。
  • Put/Call 未平倉比：Sell Put 未平倉量 / Sell Call 未平倉量。> 100% 代表下檔支撐力道強。
3. 大盤市場多空方向判讀法則
市場格局 指標特徵 建議策略
強勢多頭 散戶多空比 < 0%、P/C Ratio > 110%、大盤站穩 20MA/60MA 上 順勢偏多操作，拉回找買點。
現貨熱、期貨避險 外資期貨空單 > 3萬口、散戶多空比 ≥ 20%（過熱背離） 警惕背離風險，不宜追高。
弱勢空頭 散戶多空比 > +20%、P/C Ratio < 90%、指數破 60MA 季線 保守觀望或適度進行避險。
